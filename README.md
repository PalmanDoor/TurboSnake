# TurboSnake — Arena update

Java / jMonkeyEngine. Существующие ресурсы и пять карт сохранены.

## Запуск

Нужен **JDK 17 или новее** (именно JDK: карты компилируются при запуске).
Распакуйте весь проект. В Windows запустите **Run.bat** — он соберёт исходники и откроет игру.
Для отдельной сборки — Build.bat. В Linux: chmod +x build.sh run.sh, затем ./run.sh.
Каталог lib уже содержит зависимости; IDE и Maven не нужны.
Редактор шрифтов Hiero находится отдельно в tools, чтобы его встроенная версия
LWJGL не конфликтовала с игровым движком.

## Арена змейки

Green Arena, Desert Arena, Spike Pits и Classic 2D получили совместный режим волн.
Первые враги появляются после короткой подготовки. Каждая третья волна — босс:
Страж выпускает кольца снарядов, Колосс атакует рывками и взрывами,
Улей вызывает подкрепления. При потере здоровья боссы меняют фазу.

- W / стрелка вверх: двигаться; A/D / стрелки: поворачивать; S: тормозить.
- Space: стрелять вперёд; E: круговой импульс, уничтожающий вражеские снаряды.
- Shift: боевой рывок; пробивает обычных врагов и наносит урон кубам.
- 1: усилить урон; 2: скорострельность; 3: броня и ремонт.
- Escape: пауза в одиночной игре, меню в сетевой. Tab: игроки и статистика.

Еда и победы дают опыт; повышение уровня даёт выбор улучшения. Между волнами
есть время собрать ремонт и бонусы. Серия быстрых побед повышает комбо.
Дополнительные события: двойные награды, перегрузка оружия, метеорный фронт.
Красные кольца предупреждают о взрывах. Белые глаза и разные силуэты помогают
различать персонажей. Новые модели создаются кодом, без дополнительных загрузок.

Рекорды хранятся в progress.properties рядом с settings.properties
(%APPDATA%/SSnake3D в Windows). Улучшения относятся к текущему забегу.

## Карты

- Green Arena: увеличен обзор над рельефом; еда располагается на поверхности.
- Desert Arena: увеличен обзор, улучшено управление; песчаная буря без случайного замораживания.
- Spike Pits: увеличен обзор ловушек и манёвренность.
- Classic 2D: исправлена высота пола/сетки, камера ближе к бою.
- Tank Battle 2D: сохранён отдельный режим танков; добавлен босс Командир в одиночной игре,

  Общие припасы в сети выдаёт хост.

## Сеть

До четырёх игроков. В лобби можно подключиться напрямую к IP хоста.
UDP 45679 — игра, UDP 45678 — поиск в локальной сети. Для интернета нужен
доступ к UDP-порту хоста; адрес виртуальной LAN также можно ввести напрямую.
На всех компьютерах должна быть эта версия и одинаковые карты.

В арене змейки хост рассчитывает движение, бой, рост и награды.
Клиент предсказывает своё движение и получает коррекции. Ввод передаётся
регулярно; старые снимки отбрасываются. Важные события подтверждаются и
повторяются при потере пакета. Пакеты привязаны к адресу участника и текущему
матчу. При выходе одного игрока остальные продолжают кооперативный забег.
Карта выбирается по идентификатору, а не только по порядку файлов.
Ледяные шипы и дождевые шарики получают снимки состояния от хоста;
лужи замедляют каждого игрока отдельно. Торможение передаётся вместе с вводом.

Tank Battle сохраняет прежнюю модель сетевого PvP с локальным движением и
получением урона; полная авторитетная симуляция танков на хосте не реализована.
Боты и Командир доступны в одиночном танковом режиме.

## Проверки

build.sh компилирует все классы/карты и запускает RegressionTests.
NetworkSmoke запускает два настоящих игровых процесса через UDP-посредник:
20% пакетов теряются, часть дублируется и приходит с задержкой.
Команда: `java -cp ".:lib/*:build/tests" NetworkSmoke` (в Windows разделитель `;`).
VisualSmoke проверяет бой, фазы босса, паузу и перезапуск карты.
GitHub Actions запускает эти проверки, меню и все карты с OpenGL через Xvfb/Mesa,
затем сохраняет скриншоты и архив со скомпилированными классами.
Длительный баланс, задержки реального интернета и совместимость с конкретными
видеодрайверами следует проверять игровыми сессиями.
